# agrinho-reciclagem-
Resumo Executivo do Projeto: Reciclar é Preservar
O projeto consiste no desenvolvimento de uma plataforma digital educativa focada em sustentabilidade e gestão de resíduos sólidos, alinhada com as diretrizes do Programa Agrinho. O site serve como uma ferramenta de conscientização ambiental, conectando conceitos teóricos à prática diária, tanto no ambiente escolar quanto no familiar e no campo.

1. Objetivos do Projeto
Educação Ambiental: Disseminar conhecimento prático e acessível sobre o ciclo de reaproveitamento de materiais.
4. Impacto Esperado
Como proposta para o Agrinho, o site atua como um recurso didático digital de apoio. Espera-se que, ao interagir com a página, os estudantes compreendam que a sustentabilidade defendida pelo programa se aplica desde a gestão das propriedades rurais até a rotina urbana, promovendo uma consciência global a partir de ações locais.
